# Student Management System

**MCA III Semester – Python Programming Project**

## Features

- ✅ Add, Update, Delete, Search student records
- ✅ Store data using JSON files
- ✅ Sort by name or marks
- ✅ Admin login authentication
- ✅ Generate reports (topper, average, grades)
- ✅ **Modern Web UI (Flask)**
- ✅ Exception handling
- ✅ Modular & well-commented code

## How to Run

### Console Version
```bash
python student_management.py
```
Login: `admin` / `admin123`

### Web UI Version ⭐
```bash
pip install flask
python app.py
```
Open: **http://127.0.0.1:5001**  
Login: `admin` / `admin123`
